4Method

Each surface holds 25 positives, 15 negatives and 10 near-misses. A positive fact is true only when its quote is in the cited file. A negative case must produce no mapped finding. A near-miss names the lookalike that must not be emitted: Minecraft Bedrock is not AWS Bedrock, a CSS cursor is not the Cursor IDE, Claude Bernard is not Claude.

These are not private tenant dumps. One documented format is exercised per surface. That is the sampling frame, not the whole surface.

Table 3. Sampling frame.

codeMinimal application tree (Python or Node, plus optional agent config).
identityOkta GET /api/v1/apps JSON export, status ACTIVE.
gatewayLiteLLM-style JSONL spend log (one record).
lowcoden8n workflow export JSON (id, name, nodes, connections).
saasSlack admin approved-app record JSON, with workspace id.
cloudJSONL record in the AWS inventory dump shape (agent or lambda).
endpointLinux home-directory fragment with vendor config paths.
networkJSONL DNS log row with src_ip, query and ts.
runtimeosquery processes JSON array (name, path, cmdline, pid).

Fact-level precision, recall and F1 are primary. A positive case is detected if any planted fact comes back. Any mapped finding on a negative or near-miss is a false positive. Specificity, false-positive rate, balanced accuracy and Matthews correlation use that case table. Crashes and timeouts leave the denominator and are counted as errors. A 1,000-draw bootstrap over cases gives a 95% interval on fact F1.

Estate recall counts positives on unread surfaces as misses. The lexicon reference applies the published alias list to the artifact text, including paths. It does not read the answer key.
